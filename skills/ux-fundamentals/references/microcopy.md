# 마이크로카피 (이 스킬 내장)

화면 안 문구 — CTA, 상태, 에러, 빈상태, 툴팁, aria-label, i18n. **구조와 함께** 고친다.

## 뿌리

**사용자가 다음에 무엇을 할지 알고 편안하게 하는가?** 공급자/개발자 본위 금지.

## 5 코어밸류 (판정 시)

명확함 · 간결함 · 친근함 · 존중 · 공감 — 충돌 시 사용자 목표 우선.

## 규칙

1. **사용자 언어** — 내부 모델명·엔진·코드 식별자를 라벨에 노출하지 않는다
2. **상황 → 이유 → 다음 행동** — 특히 에러·미완료·차단 (Navigating)
3. **동사+대상 CTA** — 같은 패턴으로 유사 surface 통일 (`~하기`, `Use …`)
4. **부정·강요 최소** — 차단 대신 실행 가능한 다음 행동 권유
5. **기능 나열 금지** — 결과 상황 한 줄을 보조 설명에 (라벨은 짧게 유지)
6. **i18n 쌍** — locale 하나만 고치지 않는다. 톤·용어 통일

## 피드백 문구와 구조

- 가벼운 완료: 짧은 인라인 (`준비됐어요` / `Ready`)
- 실패·차단: 상황+해결 (다이얼로그 본문)
- 진행: `… 중` / `Creating…` — feedback 축과 동일 어휘
