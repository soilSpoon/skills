# 시각 흐름

## 원칙

1. **다음 행동** — 상태 → 이유 → 행동 (빈/실패만 금지)
2. **동일 hierarchy** — surface-contract 수직 순서
3. **단일 focal** — 주 행동 하나 지배적
4. **인과 단서** — commit 후 입력→미리보기 결과 연결 (짧고 transient)
5. **근접 그룹** — 입력·CTA·상태 한 surface 안
6. **인지 부하** — 화려함이 정보 전달을 가리지 않게

## 미리보기 영역 역할

행동 진입점이 **아님**. 결과·상태 피드백만 (conflict-resolutions).
