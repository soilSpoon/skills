# 점진 공개 (disclosure)

## 원칙

1. **공유 스캐폴드** — 유사 surface 동일 (제목)(본문)(액션). 제목이 반복 CTA 구분.
2. **선행조건** — 필요 시 **present-but-disabled** + 다음 행동 힌트 (원인→결과 사슬).
3. **시그니파이어** — 미완료도 primary 행동이 명확히 읽히게.
4. **정규 경로 하나** — 같은 목적에 사이드바·플로팅·미리보기 이중 진입 금지.
5. **과도한 접힘 금지** — 접혀도 상태 요약·주 행동 단서 유지.
6. **순서 있는 퍼널** — 다단계는 청크 + 진행 표시.
