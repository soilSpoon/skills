# 설계 단계 실험

## 목적

계약 확정 **전** 레이아웃 가설 비교. **축 하나·가설 2–3개**만.

## when NOT

- 프로덕션 variant 토글
- 완료 상태만 촬영 (차이 안 남)
- 가설 4개 이상 동시 유지

## 절차

1. 측정 가능한 차이 정의 (CTA Y, 필드 노출 여부)
2. 동일 시나리오·locale 스크린샷
3. checklist로 판정
4. **하나 선택** → variant 코드 제거 → surface-contract 단일화

## 교훈 (일반)

여러 layout variant가 **실질 2그룹**으로 수렴하면, 비교는 "카드 상단 CTA vs 하단 sticky"처럼
**축 단위 이분법**으로 단순화한다. 세부 배지·sticky 미세차는 사용자 체감이 작을 수 있다.
